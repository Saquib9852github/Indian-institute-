# Indian Typing Institute

यह project एक Computer & Typing Institute Website / Management System है, जिसे students और institute management की जानकारी को आसान और digital तरीके से manage करने के लिए बनाया गया है।

## 📌 Features
- Student Registration
- Typing Course Information
- Computer Course Details
- Faculty Information
- Fee Management
- Attendance System
- Contact Form
- Responsive Website Design

## 💻 Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL

## 📚 Available Courses
- English Typing
- Hindi Typing
- DCA
- PGDCA
- Tally Prime
- MS Office
- Python Programming
- Web Development

## 🎯 Project Objective
इस project का उद्देश्य students को typing और computer courses की जानकारी online उपलब्ध कराना और institute management को digital बनाना है।
